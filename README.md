# Financial Risk Management

Coursework, labs, and assignments for a Financial Risk Management course (FRME, Spring 2026).
This repo tracks my code, methodology, and results as I work through market and other risk topics.

## Contents

| Folder | What's inside |
|--------|---------------|
| `lectures/L1/` | Session 1 — Risk Landscape & Types of Risk |
| `lectures/L2/` | Session 2 — Market Risk Basics (lab + notebook) |
| `lectures/L3/` | Session 3 — Value at Risk (lab + data) |
| `lectures/L4/` | Session 4 — Expected Shortfall & Backtesting |
| `lectures/L5/` | Session 5 — Credit Risk I, single name |
| `lectures/L6/` | Session 6 — Credit Risk II, portfolio |
| `lectures/L7/` | Session 7 — Liquidity & Operational Risk |
| `lectures/L8/` | Session 8 — Derivatives (+ QuantLib supplement) |
| `lectures/L9/` | Session 9 — Portfolio Risk & Optimization, Factor Models |
| `assignments/A1/` | Assignment 1 — Market Risk (portfolio VaR / ES / backtesting) |
| `assignments/A2/` | Assignment 2 — Credit, Liquidity & Operational Risk |

Each lecture folder holds the session slides plus its notebook and data. Each
assignment folder is self-contained: the brief, the marker feedback, the notebook,
and the pinned data snapshot it loads.

## Tools

- Python (pandas, numpy, matplotlib, scipy, arch) in Jupyter notebooks
- Data provided as CSV/XLSX reference files and dated CSV snapshots

## Notes

Data files here are course-provided reference snapshots and dated market snapshots
used to reproduce the analysis. No live market feeds or credentials are stored in
this repo.
