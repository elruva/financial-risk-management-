Setup once (run this before any method)

import numpy as np
import pandas as pd
import yfinance as yf
from pypfopt import expected_returns, risk_models
from pypfopt import EfficientFrontier, HRPOpt, objective_functions
from pypfopt import black_litterman, BlackLittermanModel
import riskfolio as rp

# 1) Pick your stocks (tickers) and download daily prices
available = ["AAPL", "MSFT", "JPM", "XOM", "JNJ", "PG", "GLD", "TLT"]
prices = yf.download(available, start="2021-07-01", end="2026-07-01",
                     auto_adjust=True)["Close"]
prices = prices[available].dropna()      # keep the column order, drop empty rows

# 2) The two ingredients almost every method needs
mu   = expected_returns.mean_historical_return(prices)        # expected yearly return per stock
S_lw = risk_models.CovarianceShrinkage(prices).ledoit_wolf()  # smoothed risk-and-correlation table

# 3) Daily simple returns (needed by risk parity and HRP)
simp_ret = prices.pct_change().dropna()

RF = 0.04    # risk-free rate per year, e.g. 4%

# A tiny helper so every method prints its weights the same way
def show(weights):
    """Print each stock's weight as a percentage, biggest first."""
    s = pd.Series(weights).sort_values(ascending=False)
    for name, wgt in s.items():
        print(f"  {name:6s} {wgt*100:5.1f}%")
Good to know. PyPortfolioOpt covers most methods. Equal Weight and Inverse Volatility are one-line formulas with no library. Equal Risk Contribution and CVaR Risk Parity use riskfolio-lib, because PyPortfolioOpt has no risk-parity solver. Methods 1 and 2 are benchmarks (simple yardsticks), not optimizers.

IMPORTANT, read once. In PyPortfolioOpt, ef.max_sharpe() ignores any extra rules you add with add_objective or add_constraint, because of a math shortcut it uses inside. So for the Robust (9) and ESG (10) methods you MUST use ef.min_volatility() or ef.max_quadratic_utility(), never ef.max_sharpe().

The ten methods

1
Equal Weight (1/N)
none
What Put the same fraction of money in every stock. With 8 stocks, each gets 1/8.
Use A simple benchmark. It is famously hard to beat and needs no estimates.
w = pd.Series(1/len(available), index=available)
show(w)
Needs just the list of tickers (available).
Careful it ignores risk, so jumpy stocks carry most of the risk.
2
Inverse Volatility
none
What More money in calm stocks, less in jumpy ones. Volatility means how much a stock wiggles.
Use A quick, cheap, risk-aware benchmark.
vols = np.sqrt(np.diag(S_lw))            # each stock's yearly volatility
w = pd.Series((1/vols) / np.sum(1/vols), index=available)
show(w)
Needs S_lw (to read the volatilities).
Careful it looks at each stock alone and ignores how stocks move together.
3
Maximum Sharpe (Markowitz)
PyPortfolioOpt
What The mix with the best return for its risk. Sharpe ratio = extra return divided by risk. The classic tangency portfolio.
Use When you trust your return estimates and want the best risk-adjusted mix.
ef = EfficientFrontier(mu, S_lw)
ef.max_sharpe(risk_free_rate=RF)
w = ef.clean_weights()    # tidy up: tiny weights set to 0
show(w)
Needs mu and S_lw.
Careful it reacts strongly to mu, so small changes in your guesses swing the weights a lot.
4
Minimum Variance (GMV)
PyPortfolioOpt
What The least-risky mix, ignoring returns. GMV means Global Minimum Variance.
Use When you do not trust return forecasts and just want the calmest portfolio.
ef = EfficientFrontier(None, S_lw)   # None means "do not use returns"
ef.min_volatility()
w = ef.clean_weights()
show(w)
Needs S_lw only.
Careful it can pile most of the money into a few low-risk stocks.
5
Equal Risk Contribution (ERC)
riskfolio-lib
What Weights so every stock adds the same amount of risk. The money is not shared equally, the risk is.
Use When you want risk spread evenly rather than money spread evenly (the "all-weather" idea).
port = rp.Portfolio(returns=simp_ret[available])
port.assets_stats(method_mu='hist', method_cov='ledoit')   # estimate the inputs
w = port.rp_optimization(model='Classic', rm='MV', rf=0, b=None, hist=True)
# rm='MV' = balance variance risk;  b=None = equal 1/N risk share = true ERC
show(w["weights"])       # riskfolio returns a table with a 'weights' column
Needs simp_ret.
Careful the result is a DataFrame, so read the "weights" column (not a plain dict).
6
CVaR Risk Parity
riskfolio-lib
What Like ERC, but it balances each stock's share of tail loss instead of variance. CVaR is the average loss on the worst days.
Use When you care about crash losses more than everyday wiggles.
port = rp.Portfolio(returns=simp_ret[available])
port.assets_stats(method_mu='hist', method_cov='ledoit')
w = port.rp_optimization(model='Classic', rm='CVaR', rf=0, b=None, hist=True)
show(w["weights"])
Needs simp_ret.
Careful CVaR comes from history, so it needs enough data and is noisier than variance.
7
Black-Litterman
PyPortfolioOpt
What Start from what the whole market implies, then nudge it with your own views. Market wisdom plus your opinions.
Use When you have a few specific views and want gentle, sensible tilts.
# market_prices = price history of a market index (for example SPY)
market_prices = yf.download("SPY", start="2021-07-01", end="2026-07-01",
                            auto_adjust=True)["Close"]
mkt_caps = {t: 1e9 for t in available}    # market value of each firm (use real numbers)
view_dict = {"AAPL": 0.10}                # "I expect AAPL to return 10% per year"

delta = black_litterman.market_implied_risk_aversion(market_prices)
prior = black_litterman.market_implied_prior_returns(mkt_caps, delta, S_lw)
bl = BlackLittermanModel(S_lw, pi=prior, absolute_views=view_dict)

ef = EfficientFrontier(bl.bl_returns(), bl.bl_cov())
ef.max_sharpe(risk_free_rate=RF)
w = ef.clean_weights()
show(w)
Needs S_lw, a market index price series, market caps, and your views.
Careful replace the placeholder market caps with real values, or the starting point is wrong.
8
Hierarchical Risk Parity (HRP)
PyPortfolioOpt
What Groups stocks that move together into a tree, then splits risk down the tree. It never inverts the risk table, so it stays stable.
Use With many stocks or shaky data, where classic methods become unstable.
hrp = HRPOpt(returns=simp_ret[available])
hrp.optimize()
w = hrp.clean_weights()
show(w)
Needs simp_ret.
Careful give it returns (simp_ret), not prices.
9
Robust weights (L2)
PyPortfolioOpt
What A minimum-variance mix with a rule that pushes weights apart, so money is not dumped into one or two names.
Use When plain optimizers give one giant position and you want a spread-out, stable mix.
ef = EfficientFrontier(mu, S_lw)
ef.add_objective(objective_functions.L2_reg, gamma=0.1)  # bigger gamma = more spread out
ef.min_volatility()                                      # NOT max_sharpe (see the box)
w = ef.clean_weights()
show(w)
Needs mu and S_lw.
Careful use min_volatility or max_quadratic_utility here, never max_sharpe.
10
ESG-tilted portfolio
PyPortfolioOpt
What The best risk-adjusted mix that also keeps the average ESG score above a target. ESG is a sustainability score per stock.
Use When you must meet a sustainability rule while still optimizing.
# esg_scores: one score per stock, in the same order as `available`
esg_scores = pd.Series({t: 50 for t in available})   # replace with real scores
esg_target = 60                                       # required average score

ef = EfficientFrontier(mu, S_lw)
# add_constraint takes a small function of the weights w:
ef.add_constraint(lambda w: esg_scores.values @ w >= esg_target)
ef.max_quadratic_utility(risk_aversion=1)            # NOT max_sharpe (see the box)
w = ef.clean_weights()
show(w)
Needs mu, S_lw, and an ESG score for each stock.
Careful if your ESG data is a risk score where lower is better, flip the rule (use <=).

Glossary

Expected returns (mu): your best guess of each stock's future yearly return.
Covariance matrix (S_lw): a table showing how much each pair of stocks moves together.
Ledoit-Wolf shrinkage: a way to smooth that table so it is more reliable when data is limited.
Volatility: how much a stock's price wiggles; higher means riskier.
Risk contribution: how much of the portfolio's total risk comes from one stock.
Tangency / max-Sharpe portfolio: the mix with the best return for its risk.
Risk parity: weights chosen so every stock adds the same risk.
CVaR: the average loss on the worst days; a measure of crash (tail) risk.
